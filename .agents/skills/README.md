# Skills compartidas del expediente

Esta carpeta es la fuente canónica de procedimientos reutilizables y **revisados** para Claude Code y Codex en este expediente.

Cada skill aprobada tendrá su propia carpeta y un `SKILL.md`. Antes de incorporarla, verificar su alcance, fuentes, pruebas y ausencia de secretos o datos personales. Las skills personales de `~/.claude/skills` y `~/.codex/skills` no se copian aquí automáticamente.

No hay enlaces, hooks ni sincronización automática entre instalaciones. El relevo de cambios se hace con Git y revisión humana.
